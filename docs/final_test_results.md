# Результаты независимой final-test оценки

## Условия эксперимента

Итоговый запуск выполнен по заранее зафиксированному
[`final_test_protocol.md`](final_test_protocol.md) без повторного выбора моделей
по test-данным. Период оценки — 02.01.2020–31.12.2025. Для каждого из тикеров
`AAPL`, `JPM`, `SPY` и `XOM` получено 1 508 однодневных прогнозов, всего 6 032
наблюдения на модель. Fingerprint запуска:
`1f13f8ce5ae4d49529a22a2dff5c0ff557a7527195f55fb5be186d11f54911e6`.

Все четыре модели используют одинаковые даты и фактические доходности.
Пропусков и дубликатов ключей нет. Для обычной и residual LSTM завершены все
десять seed каждого тикера; итоговые LSTM-прогнозы являются средним десяти
выровненных прогнозов.

## Ошибка прогноза доходности

Pooled-метрики рассчитаны по всем 6 032 наблюдениям, а не как среднее четырёх
ticker-level метрик.

| Модель | MAE, б.п. | RMSE, б.п. | RelMAE | OOS R² | Directional accuracy |
|---|---:|---:|---:|---:|---:|
| `naive_zero` | 125.471 | 186.359 | 1.0000 | 0.0000 | 0.0020 |
| ARIMA | 125.578 | 186.378 | 1.0009 | -0.0002 | 0.5104 |
| LSTM | **125.376** | 186.556 | **0.9992** | -0.0021 | 0.5197 |
| ARIMA-LSTM | 125.909 | 187.914 | 1.0035 | -0.0168 | **0.5224** |

LSTM снизила pooled MAE относительно `naive_zero` на 0.095 б.п., или на
0.076%, но увеличила RMSE на 0.197 б.п. ARIMA увеличила MAE на 0.107 б.п. и
RMSE на 0.019 б.п. ARIMA-LSTM увеличила MAE на 0.438 б.п. и RMSE на
1.555 б.п. Поэтому первое место LSTM по MAE не означает подтверждённого
преимущества по совокупности критериев.

По тикерам результаты различаются:

| Тикер | `naive_zero` MAE/RMSE | ARIMA MAE/RMSE | LSTM MAE/RMSE | ARIMA-LSTM MAE/RMSE |
|---|---:|---:|---:|---:|
| AAPL | 138.458 / 200.081 | 138.140 / 199.907 | **138.011 / 198.407** | 138.153 / 198.737 |
| JPM | 129.732 / 197.342 | 129.768 / **196.273** | **129.399** / 198.593 | 129.952 / 200.101 |
| SPY | **85.689** / 131.056 | 85.863 / **130.687** | 85.957 / 132.658 | 87.424 / 136.182 |
| XOM | **148.004 / 206.800** | 148.542 / 208.282 | 148.136 / 206.905 | 148.107 / 207.761 |

Минимум MAE и минимум RMSE принадлежат одной модели только для AAPL и XOM.
На JPM и SPY выбор модели зависит от метрики. Directional accuracy обучаемых
моделей находится в диапазоне 0.5104–0.5224 на pooled-выборке, но это не
сопровождается снижением RMSE. Значение directional accuracy нулевого прогноза
близко к нулю по определению метрики: прогноз с нулевым знаком совпадает только
с точно нулевой фактической доходностью.

## Восстановленная цена

По macro-average ценовым метрикам LSTM получила минимальные sMAPE `0.012536` и
MASE `4.7502`; у `naive_zero` они равны `0.012546` и `4.7562`. Различия малы и
согласуются с разницей pooled MAE доходности менее 0.1 б.п. ARIMA-LSTM получила
sMAPE `0.012589` и MASE `4.7698`, то есть не сохранила validation-преимущество.

## Режимы волатильности

Ранжирование pooled MAE меняется между заранее заданными режимами:

| Режим | Лучшая модель | MAE, б.п. | Следующий результат, б.п. |
|---|---|---:|---:|
| low | ARIMA-LSTM | 86.304 | ARIMA — 86.366 |
| medium | LSTM | 98.680 | ARIMA-LSTM — 99.011 |
| high | ARIMA | 164.753 | `naive_zero` — 164.779 |

Для pooled RMSE лучшей была ARIMA в low- и high-режимах, LSTM — в
medium-режиме. Разница между первым и вторым местом по MAE составляет
0.026–0.331 б.п. Протокол не предусматривает отдельного статистического теста
внутри каждого режима, поэтому таблица
подтверждает смену описательного ранжирования, но не доказывает преимущество
модели в конкретном режиме.

## Статистические сравнения

Ни одно из 50 сравнений Diebold–Mariano не отвергло нулевую гипотезу после
поправки Holm при уровне 0.05. Для pooled absolute loss наименьшее
скорректированное p-value равно `0.3091` в сравнении ARIMA-LSTM с LSTM; для
pooled squared loss — `0.1047` в том же сравнении.

95%-е moving-block bootstrap интервалы показывают:

- pooled-разница MAE LSTM минус `naive_zero` равна -0.095 б.п. с интервалом
  [-0.48; 0.37] б.п.; интервал включает ноль;
- pooled-разница RMSE ARIMA-LSTM минус LSTM равна 1.36 б.п. с интервалом
  [0.43; 2.36] б.п.; гибрид имеет большую ошибку;
- для SPY гибрид уступает LSTM по MAE на 1.47 б.п. с интервалом
  [0.40; 2.90] б.п. и по RMSE на 3.52 б.п. с интервалом [0.59; 7.29] б.п.;
- для XOM ARIMA уступает `naive_zero` по RMSE на 1.48 б.п. с интервалом
  [0.23; 2.84] б.п.

Bootstrap-интервалы оценивают размер эффекта, а DM/Holm — различие средних
loss differential с учётом временной зависимости и множественных сравнений.
Эти процедуры отвечают на разные вопросы, поэтому интервал, не содержащий
ноль, может сочетаться с неотклонённой DM-гипотезой после Holm.

## Устойчивость между seed

Стандартное отклонение MAE между десятью seed составляет 0.090–0.896 б.п. для
обычной LSTM и 0.143–1.985 б.п. для ARIMA-LSTM. Для RMSE диапазоны равны
0.223–4.698 и 0.243–5.873 б.п. соответственно. Разброс не меняет pooled-вывод:
гибрид не превосходит отдельную LSTM. Наибольшая вариативность наблюдается для
SPY; выбор лучшего отдельного seed не использовался.

## Выводы по гипотезам

- **H1 не подтверждена:** ни одна обучаемая модель не снизила одновременно
  pooled MAE и RMSE относительно `naive_zero` с bootstrap-интервалом в пользу
  модели и значимым Holm-adjusted DM.
- **H2 не подтверждена:** ARIMA-LSTM уступила отдельным ARIMA и LSTM по обеим
  pooled-метрикам; её RMSE статистически больше RMSE LSTM по bootstrap.
- **H3 поддерживается описательно:** лучшая по pooled MAE модель меняется между
  low-, medium- и high-режимами. Статистическая значимость этой смены отдельно
  не проверялась.
- **H4 не подтверждена:** стандартное отклонение MAE между seed находится в
  диапазоне 0.090–1.985 б.п., но результаты не согласованы между активами и
  метриками.

На независимом периоде 2020–2025 ни одна обучаемая модель не снизила обе
pooled-метрики относительно нулевого прогноза с подтверждением по заранее
заданным статистическим процедурам. Validation-преимущество ARIMA-LSTM не
перенеслось на final test. Этот отрицательный результат не изменяет протокол и
указывает, что найденная на validation структура не обобщилась на последующий
рыночный период.
